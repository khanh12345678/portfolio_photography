# Website Improvement Ideas

These are improvement ideas for the current portfolio/photography website based on `main.html`, `contact.html`, `style.css`, and `style_contact.css`.

## 1. Layout & Navigation
- Use a consistent navigation bar across `main.html` and `contact.html`.
- Replace placeholder links like `about` and `home` with functional pages or remove them.
- Add a branded logo or site title area instead of only the icon hover block.
- Consider a sticky header and a mobile-friendly hamburger menu.
- Use semantic HTML such as `<nav>`, `<header>`, `<main>`, and `<footer>`.

## 2. Homepage Content & Messaging
- Improve the hero headline and supporting text to make the brand stronger.
- Change the button text to something like `View Portfolio` or `Explore Work`.
- Make the button scroll smoothly to the gallery or open a booking/contact form.
- Add a short services section describing what kinds of shoots you offer.

## 3. Gallery Experience
- Add gallery categories or filters (e.g. portraits, cosplay, editorial) to help visitors explore.
- Implement a lightbox or modal so users can view larger versions of selected photos.
- Add captions or brief descriptions for featured photos.
- Use optimized images or smaller mobile versions to improve performance.

## 4. Design Polish
- Improve readability of hero text with a darker overlay or gradient over the background image.
- Use a consistent color palette across both pages.
- Select 1–2 font families and apply them consistently across the homepage and contact page.
- Consider stronger spacing, alignment, and visual hierarchy for sections.

## 5. Contact Page Enhancements
- Add a contact form with name, email, and message fields.
- Add a brief intro line like `Reach out for bookings and inquiries`.
- Use an informative page title instead of `Document`.
- Add optional elements such as location notes, availability, or testimonials.

## 6. Accessibility & Semantic Improvements
- Add alt text for all images, including gallery photos.
- Ensure the site works for keyboard users and screen readers.
- Make the navigation and button focus-visible.

## 7. Technical & Performance Fixes
- Fix broken or placeholder links such as `href="http://"`.
- Consolidate CSS where possible so shared styles are not duplicated.
- Add metadata for SEO and social sharing (description, Open Graph tags).
- Test responsiveness on all screen sizes and adjust mobile layout as needed.

## 8. Storytelling & Business Focus
- Add an About section or page to explain your style and experience.
- Highlight featured work or best shots so visitors see your strongest images first.
- Consider adding client testimonials, recent projects, or a short portfolio narrative.

## 9. Interactivity
- Add smooth scrolling for navigation or CTA button actions.
- Use subtle animations for section entrances and image hover states.
- Add a scroll indicator or prompt to encourage visitors to explore the gallery.
